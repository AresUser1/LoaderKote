### 📱 Инструкция по установке APK:
1. Скачайте файл **`koteloader.apk`** по ссылке выше.
2. Откройте файл и подтвердите установку в Android (разрешите установку из вашего браузера/проводника).
3. При первом запуске войдите в свой аккаунт Telegram по номеру телефона или через QR-код.
4. Разрешите приложению отображение **«Поверх других приложений»** (необходимо для работы наэкранного плавающего HUD).

### 🧰 Инструкция для разработчиков модулей (SDK):
1. Скачайте архив **`kote-module-sdk.zip`** и распакуйте его на ПК или сервере.
2. Внутри находится всё необходимое для написания модулей:
   - `include/module_abi.h` — заголовочный файл C-API (ABI 3).
   - `README.md` и `LUA_GUIDE.md` — подробная документация по созданию нативных C и Lua модулей, инлайн-кнопок и колбэков.
   - `build.sh`, `Makefile`, `CMakeLists.txt` — сборка под Android NDK (`arm64-v8a`) и Linux/WSL.
   - `examples/` и `src/` — рабочие примеры и шаблон нового модуля (`my_module.c`).
3. Для сборки выполните `./build.sh` — готовые Android `.so` появятся в `out/android-arm64-v8a/`; для Linux используйте явный `--host`.
4. Отправьте файл `.so` или `.lua` в «Избранное» Telegram и ответьте на него командой `.install` для мгновенной установки!

> [!TIP]
> **Автообновления (OTA):** Приложение умеет обновляться автоматически! Вам не нужно вручную проверять этот репозиторий: во вкладке **«Модули»** или **«Настройки»** нажмите кнопку **«Обновления»**, чтобы проверить и установить свежую версию в один тап.

## ✨ Основные возможности

### 🐾 Наэкранный плавающий HUD (Floating Overlay)
* **Всегда под рукой**: вызывается нажатием на плавающую иконку котика или плитку в шторке быстрых настроек Android (Quick Settings Tile).
* **Управление из любого приложения**: отправляйте команды, переключайте модули, запускайте сниппеты прямо во время общения в Telegram или в играх.
* **Гибкая кастомизация интерфейса**:
  * Выбор расположения навигационных кнопок: **Сверху**, **Снизу** или **Сбоку**.
  * Точная регулировка ширины (75%, 85%, 95%) и высоты окна (200dp, 240dp, 300dp).
  * Исправленный ввод текста без обрезки полей на любых клавиатурах.

### 🚀 Собственное нативное C++20 MTProto Ядро
* **Низкоуровневая реализация**: собственный криптографический стек (AES-IGE, SHA-256, RSA, быстрая факторизация Леймера, протокол авторизации MTProto 2.0).
* **Экстремальная автономность**: прямой сокетный транспорт без тяжелых фоновых фреймворков обеспечивает минимальный расход аккумулятора и оперативной памяти.
* **Встроенный обход блокировок**: поддержка SOCKS5 и нативного FakeTLS / MTProto-прокси прямо из настроек.

### 🧩 Двойной модульный рантайм (Lua + C/C++)
* **Скриптовые модули (`.lua`)**: пишите скрипты в любом текстовом редакторе прямо на телефоне, устанавливайте без компиляции, редактируйте на лету.
* **Нативные модули (`.so`, ABI 3)**: максимальная скорость для тяжелых алгоритмов, парсеров и медиа-фильтров.
* **Мгновенный Hot-Reload**: включение, отключение, добавление и обновление модулей без перезапуска приложения.
* **Встроенное хранилище `koto.db.*`**: каждому модулю доступно изолированное SQLite-хранилище данных.
* **Контроль совместимости (`min_host_version`)**: автоматическая защита от запуска модулей на устаревших версиях клиента.

### 🛡 Надёжность и сохранность ваших данных
* **Автоматический бэкап сессии и модулей**: при авторизации и установке модулей создаётся защищённая резервная копия в постоянную память устройства:
  ```
  /sdcard/Download/KoteLoader_Backup/
  ```
* **Бесшовная переустановка**: при удалении и повторной установке APK сессия Telegram и модули восстанавливаются автоматически — повторный вход не потребуется!

### 🎬 Интеграция с нативным плеером Telegram
* При скачивании и отправке видео (`.mp4`, `.mov`, `.webm`) движок генерирует превью-кадры, определяет соотношение сторон и включает потоковое воспроизведение (`supports_streaming = true`). Видео открывается в плеере Telegram мгновенно, без задержек и ожидания полной загрузки.

### 👥 Менеджер мультиаккаунтов (Twins)
* Подключайте несколько аккаунтов (твинков) и управляйте ими одновременно через удобное меню.

### Как установить модуль:
1. **Через приложение**: откройте вкладку **«Модули»** → **«Репозиторий»** (официальный каталог уже подключён) и нажмите «Установить» на нужном модуле.
2. **Через Telegram**: отправьте файл (`.lua` или `.so`) документом в любой чат (например, в «Избранное») и ответьте на него командой `.install`.
3. **Через плавающий HUD**: откройте оверлей поверх экрана и выберите файл через проводник.

### Как обновить модуль:
* **Пользовательский модуль (`.lua`/`.so`)**: откройте карточку модуля в списке и нажмите **«Обновить модуль из файла»**. Хост мгновенно заменит файл и перезагрузит его в памяти без перезапуска приложения!
* **Системные модули ядра**: обновляются вместе с ядром через кнопку **«Обновления»** в верхней панели с просмотром подробного **Changelog**.

### Пример простого модуля на Lua:

```lua
name = "quick_tag"
description = "Быстрый ответ с цитатой"
version = "1.0.0"
min_host_version = 2 -- Требует KoteLoader 0.1.1+

commands = {
    hi = { doc = "Поприветствовать собеседника", usage = "" }
}

function on_message(msg)
    if not msg.out then return end

    if msg.text == ".hi" then
        msg:edit("👋 **Привет от Kotogram Engine!**\n> Быстрый юзербот на C++ и Lua")
    end
end
```

Полное руководство по разработке: 📖 [LUA_GUIDE.md в основном репозитории](https://github.com/AresUser1/Kotogram/blob/main/docs/LUA_GUIDE.md).

  * Автоматическое распознавание отозванной/мёртвой сессии (`AUTH_KEY_UNREGISTERED`, `SESSION_REVOKED`, `USER_DEACTIVATED`, `401`): клиент плавно возвращает на экран входа вместо зацикливания на ошибках.
* 🌐 **Прокси на лету и устойчивость сессии (v0.2.6)**:
  * Настройки прокси применяются немедленно — активный клиент переподключается без перезапуска приложения, фоновый сервис восстанавливает прокси-соединение при появлении сети.
  * При отсутствии интернета сессия восстанавливается локально и сразу открывается главный экран без ошибочного сброса на форму входа.
* 📎 **Надёжная отправка файлов из модулей (v0.2.5)**:
  * Файлы из модулей с `on_callback` всегда отправляются напрямую через `sendMedia` юзербота; команда `.cfg` теперь проверяет права OWNER.
* 🎭 **Role-Play модуль и FakeTLS-прокси (v0.2.3 – v0.2.4)**:
  * Добавлен нативный C++ модуль Role-Play (22 действия, `.addrp`, `.rplist`, `.setrpnick`, система прав и кастом-эмодзи).
  * Поддержка FakeTLS MTProto-прокси; исправлено автоудаление поискового сообщения в музыкальном модуле.

* 🛑 **Мгновенная остановка юзербота без зависаний (v0.2.1 Hotfix)**:
  * Устранено бесконечное зависание в состоянии «Останавливается…» (ранее поток `stop()` блокировался циклом ожидания фоновых задач в `client.cpp`).
  * Добавлены лимиты и прерывания ожидания (`ping_stop_`) в `reconnect()` и `catch_up()`, таймауты в JNI-мосте (`run_sync_timeout`) и корутинах Kotlin (`withTimeout(3000)`). Движок гарантированно завершает остановку за <2 сек.
* 🌐 **Устранение сетевого флаппинга и спама `Socket closed` (v0.2.1 Hotfix)**:
  * Android `ConnectivityManager` больше не сбрасывает соединение при колебаниях уровня мобильного сигнала или сменах точек доступа Wi-Fi (`onCapabilitiesChanged`).
  * Реконнект MTProto и опрос Bot API выполняются строго при фактической смене активного интерфейса сети с защитным дебаунсом.
* ⚡ **Автоматическая активация юзербота**:
  * Гарантированное выставление флага `userbot_enabled` при каждом старте хоста для немедленной готовности к выполнению команд.
* 🧰 **SDK Kit в каждом релизе**:
  * Архив разработчика `kote-module-sdk.zip` теперь прикрепляется к каждому официальному GitHub-релизу наряду с APK для удобной сборки сторонних модулей на C и Lua.

* 🏪 **Выделенный официальный репозиторий модулей KoteModules (v0.2.0)**:
  * Вкладка «Репозиторий» теперь по умолчанию подключена к официальному магазину модулей: `https://raw.githubusercontent.com/AresUser1/KoteModules/main/index.json`.
  * Репозиторий приложения `LoaderKote` теперь содержит исключительно обновления APK и ядра, а модули распространяются через независимый репозиторий [KoteModules](https://github.com/AresUser1/KoteModules).
* 🕹️ **Универсальный инлайн-движок для любых модулей (v0.2.0)**:
  * Инлайн-режим бота-помощника и диспетчеризация `callback_query` перенесены на уровень ядра `libkotogram` и JNI-моста.
  * Любые сторонние модули на C (`module_abi.h`) и Lua теперь могут создавать интерактивные клавиатуры, кнопки, меню и сетевые игры с колбэками (`on_callback`, `c_button`, `cb_answer`, `c_edit_message`) без добавления кода в Android-приложение.
  * Модуль русских шашек `checkers.so` полностью работает в чистом нативном коде C поверх универсального рантайма.
* ♟️ **Поддержка нативных модулей нового поколения (v0.2.0)**:
  * Добавлен нативный модуль `checkers` (v2.1.0): русские шашки на C (ABI 3) с полноценным онлайн-PvP между любыми участниками чата, свободным выбором белых/чёрных, серией ударов в 1 клик, дальнобойными дамками и реваншем.
  * Добавлен нативный модуль `copymessage` (v1.3.0): копирование защищённого контента и медиа напрямую в Избранное (.copy и .hcopy).
